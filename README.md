# 小峰 · 个人作品集

一个杂志式排版的个人作品集网站，纯手工 HTML / CSS / JavaScript 实现，无任何前端框架与第三方 UI 库。

## 项目功能

- **首屏 Hero**：大字号标题排版与色块装饰
- **技能方向**：四条技能列表，悬停交互
- **项目作品**：由 `js/main.js` 中的数据表渲染，三种杂志版式（左图右文 / 深色色块错位 / 通栏大图分栏）循环使用；新增项目只需在 `PROJECTS` 数组追加一条数据
- **关于我 / 联系方式**：个人简介与联系入口
- **深浅色主题切换**：导航栏右侧按钮一键切换，`localStorage` 记住用户选择，无记录时跟随系统偏好
- **响应式设计**：兼容桌面端与移动端（断点 900px / 640px），移动端导航折叠为汉堡菜单
- **滚动交互**：区块进入视口淡入、导航当前区块高亮、平滑滚动

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 结构 | 原生 HTML5 |
| 样式 | 原生 CSS3（CSS 变量实现主题切换） |
| 脚本 | 原生 JavaScript（ES6，无框架） |

## 目录结构

```
lab04/
├── index.html        # 页面结构
├── css/
│   └── style.css     # 样式与深浅色主题变量
├── js/
│   └── main.js       # 项目数据表、渲染与交互逻辑
└── images/           # 作品配图与个人照片
```

## 运行方式

无需构建，直接用浏览器打开 `index.html` 即可。

如需本地服务器（推荐）：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000 。
